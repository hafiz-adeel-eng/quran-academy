content = """# QuranlyHub SEO Skill #15: Content Freshness + Maintenance
## Version 1.0
### Purpose
Maintain published content for accuracy, usefulness, SEO health, UX, trust, and conversions.
Update only when evidence shows meaningful improvement is needed.
Protect intent, rankings, traffic, backlinks, internal links, conversions, authority, and trust.
Actions: no update, minor/moderate/major refresh, rewrite, consolidate, redirect, retire, or create supporting content.
### Core Rules
Never change dates without meaningful updates, rewrite only because content is old, add irrelevant text, stuff keywords, invent facts/statistics/sources/credentials/testimonials, change URLs without strong reason, or add a year unless genuinely year-specific.
Never remove useful content merely to shorten it; prioritize usefulness and accuracy over artificial freshness.
### Inputs
Required: URL/page, target keyword/topic, current content.
Recommended: dates, Search Console data, rankings, clicks, impressions, CTR, backlinks, internal links, conversions, current SERP, intent, competitors, location, and business/service changes.
Never fabricate missing data.
### Freshness Classification
Classify: Evergreen, Semi-fresh, Time-sensitive, Highly time-sensitive.
Evergreen: Tajweed definitions, Quran-learning guidance, memorization benefits.
Semi-fresh: online learning methods, teacher selection, pricing guidance.
Time-sensitive: current prices, schedules, availability, platform features.
Highly time-sensitive: temporary offers, annual dates, current events.
Review guidance: Evergreen 6–12 months; Semi-fresh 3–6; Time-sensitive 1–3 or when facts change; Highly time-sensitive when facts change.
These are review intervals, not automatic rewrite schedules.
### SERP Review
When web access is available, check current ranking pages, intent, competitors, PAA, snippets, AI-search features where visible, related searches, and formats.
Record research date, keyword, location, and relevant results reviewed.
Never assume an old SERP still reflects current intent.
### Freshness Signals
Review potentially outdated prices, courses, teachers, schedules, technology, policies, contacts, statistics, research, references, screenshots, services, URLs, CTAs, offers, locations, and local information.
Publication date alone does not determine freshness.
### Content Decay
Evidence: declining clicks/impressions/rankings/CTR/conversions, lost important queries, competitors replacing the page, changed intent, new questions, broken links, outdated information, or missing services.
Traffic status: Stable, Mild decline, Significant decline, Severe decline.
Never claim an algorithm penalty without evidence.
### Search Console
Where available compare last 28 vs previous 28 days, last 3 months vs previous 3 months, and YoY where appropriate.
Review clicks, impressions, CTR, average position, rising/falling/new/lost queries, high-impression low-CTR queries, page-2 opportunities, and intent mismatches.
### Decay vs SERP Change
Content decay = page became less useful/competitive.
SERP change = results now favor another format or intent.
If intent changed, consider a new page, different page type, consolidation, URL architecture, or cluster restructuring.
### Accuracy + Religious Safety
Verify dates, numbers, prices, policies, courses, qualifications, availability, locations, references, religious terminology, and educational claims.
If impossible: “Verification required.”
For Quran, Tajweed, Tafsir, Arabic, memorization, or Islamic education: never invent rulings, interpretations, attributions, consensus, quotations, or references.
If needed: “Scholarly review required.”
### Quality + Completeness
Compare content with SERP, intent, questions, keywords, entities, and important subtopics.
Identify missing/outdated topics, weak explanations, FAQs, practical guidance, and local/commercial information.
Review accuracy, originality, clarity, depth, usefulness, readability, organization, examples, trust, experience, and expertise.
Score 1–5 where useful; never add topics merely for word count.
### E-E-A-T + Trust
Look for genuine teaching methodology, class structure, onboarding, teacher selection, trial process, author information, organization identity, verified qualifications, credentials, and About/contact/policy pages.
If unavailable: “User/business input required.”
Check business identity, contact details, policies, pricing transparency, secure forms, accurate claims, and clear CTAs.
Never invent trust signals.
### Local + Commercial
Verify country/city, timezone, terminology, availability, local FAQs, audience needs, and local links.
Never invent offices, branches, addresses, teachers, phone numbers, or physical presence.
Review commercial pages for course names, pricing, trial offer, CTA, availability, features, format, teachers, payments, and policies.
Update only changed information.
### Internal + External Links
Check broken links, redirects, removed/new pages, weak/over-optimized anchors, orphan pages, outdated external sources, and low-quality references.
Add/replace links only when useful; prefer official, primary, reputable, or appropriate scholarly sources.
Do not mass-add links or add links merely for SEO.
### Images + Metadata
Review broken/missing images, outdated screenshots, relevance, quality, dimensions, alt text, filenames, compression, modern formats, and lazy loading.
Alt text describes the actual image; never keyword-stuff.
Review title/meta only when intent, CTR, competition, page focus, offer, or CTA changes; never use clickbait.
### Technical SEO
Preserve ranking URLs by default.
If URL changes: 301 redirect, update internal links/sitemap, check canonical, and review external references.
Check HTTP 200, indexability, no accidental noindex/blocking, canonical, and sitemap inclusion.
Schema must match visible content; possible types include Article/BlogPosting, BreadcrumbList, Organization, WebSite, Course, FAQPage where legitimate.
Never add fake reviews, ratings, or unsupported properties.
### AEO/GEO
AEO: direct answers, definitions, steps, lists, tables, FAQs.
GEO: clear entities, consistent facts, explicit relationships, structured sections, evidence, verified author/business information.
Optimize for clarity and verification, not manipulation.
### Keywords + Cannibalization
Review new/lost relevant queries, long-tail, commercial, local, and question queries.
Use only relevant terms.
Check whether another QuranlyHub page targets the same intent; choose the primary page, consolidate, redirect, or differentiate genuinely different intents.
Do not create duplicate pages.
### Topic Cluster + Consolidation
Check parent topic, supporting articles, child topics, service pages, and internal links.
Create supporting content only for genuine gaps.
Consolidate when intent is nearly identical, one page is stronger, and overlap causes cannibalization; review traffic, rankings, backlinks, intent, and links first.
### Retirement
Consider retirement when a topic is permanently irrelevant, service no longer exists, page has no useful purpose, or content cannot responsibly be maintained.
Possible actions: 301, 410, consolidation, or noindex where appropriate.
### Update Types
1. No update
2. Minor refresh
3. Moderate refresh
4. Major refresh
5. Full rewrite
6. Consolidation
7. Redirect
8. Retirement
Minor: wording/link/CTA/meta fixes, a few questions, alt text.
Moderate: multiple sections, missing subtopics, links, FAQs, metadata.
Major: intent shift, significant decay, major service changes, large gaps.
Full rewrite only when intent is fundamentally unsatisfied or content is too outdated to repair.
Preserve rankings, keywords, backlinks, internal links, and converting sections.
### Priority + Do-Not-Touch
Critical: accuracy, legal/safety, serious business/user impact.
High: significant ranking/conversion opportunity.
Medium: useful improvement.
Low: minor optimization.
If rankings are strong, traffic stable, content accurate, intent satisfied, and nothing important is outdated: do not rewrite merely for freshness.
### Measurement + Change Log
Record URL, date, update type, changed sections, reason, sources/data, reviewer, and notes.
Before major updates capture clicks, impressions, CTR, position, top queries, backlinks, conversions, title, URL, canonical, and important internal links.
After publishing monitor indexing, rankings, clicks, impressions, CTR, conversions, crawl issues, links, rich results, and engagement where available.
Consider seasonality, algorithm changes, SERP changes, and business changes.
### Regression + UX
Confirm primary keyword, intent, important topics, links, CTAs, FAQs, schema, images, author/trust signals, and useful content remain.
Check mobile headings, text width, font size, spacing, tables, images, buttons, forms, sticky elements, and navigation.
Check LCP, INP, CLS, image sizes, lazy loading, fonts, JavaScript impact, alt text, heading hierarchy, link clarity, labels, contrast, keyboard usability, and forms.
Never sacrifice performance or accessibility for unnecessary content.
### Duplicate + Anchor Rules
Avoid near-identical content across QuranlyHub pages.
Use natural anchors describing destinations.
Good: “online Tajweed classes.”
Bad: “best cheap online Quran Tajweed classes for kids in Qatar.”
Never refresh by repeatedly inserting cities or exact-match keywords.
### AI + Competitors
AI may identify outdated sections, version differences, missing questions, and checklists.
AI must not invent facts, sources, statistics, credentials, testimonials, or religious claims.
Human verification is required for sensitive content.
Use competitors only as context; do not copy content, headings, or updates.

| | | | | | |
Statuses: Discovered → Researching → Approved → Updating → Reviewing → Published → Monitoring → Complete.
### Page Health Score
Score /5: Accuracy, Freshness, Intent match, Topic completeness, SEO, Internal linking, UX, Trust, Conversion, Performance.
Diagnostic only; not a ranking guarantee.
### Decision Matrix

|---|---|
| Stable + accurate | No update |
| Minor outdated details | Minor refresh |
| Falling rankings + gaps | Moderate refresh |
| Major intent change | Major refresh |

### Publishing Checklist
Facts verified; intent preserved; keyword natural; no stuffing; title/meta reviewed; URL preserved where possible; canonical/indexability checked; links checked; images/alt text checked; schema checked; mobile checked; performance checked; CTA checked; trust checked; religious claims verified where required.
### Final QA
Ask: Was there a real reason to update? Was intent preserved? Is usefulness improved? Are changed facts verified? Was fabrication avoided? Was stuffing avoided? Were valuable assets preserved? Was mobile UX checked? Was technical SEO checked? Were links/schema/images checked? Was conversion checked? Were changes documented?
If any critical answer is No, do not mark complete.
