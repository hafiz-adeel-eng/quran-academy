QuranlyHub SEO Skill
Skill #4: Content Brief & SEO Content Architecture
Purpose

Convert keyword research, SERP intelligence, content gaps, search intent, and title strategy into a complete, actionable SEO content blueprint. This skill does not write the article.

Inputs

Required:

Keyword Research output
SERP Intelligence/Content Gap output
Search Intent/Title Optimization output

Recommended:

Target country/city/audience
Existing QuranlyHub URLs/content
Available services/courses
Verified brand/business information
Workflow
Define primary/secondary intent, audience, user problem, desired outcome, business/search objective.
Select page type based on SERP: service, location, course, article, guide, comparison, FAQ, supporting article, or cluster page.
Map primary, secondary, long-tail, question, commercial, local, and semantic keywords.
Build topic hierarchy from SERP evidence, gaps, questions, entities, and audience needs.
Classify topics as mandatory/high/medium/optional.
Map relevant entities and questions.
Build H1/H2/H3 structure with answer-first sections.
Plan AEO/GEO, E-E-A-T, local SEO, internal/external links, media, schema, URL, conversion, and differentiation.
Check cannibalization against existing pages.
Run QC and return the structured blueprint.
Search Intent

Document:

Dominant intent
Secondary intent
SERP evidence
Required satisfaction elements

Structure must satisfy dominant intent. Never confuse business objectives with search intent.

Keyword Strategy

Map:

Primary
Secondary
Long-tail
Questions
Commercial
Local
Semantic terms

For each, identify purpose, suggested section, and priority. Use naturally; never impose arbitrary keyword density or force every keyword.

Topic Architecture

Build:

Primary Topic → Major Topics → Subtopics → Questions

Include only topics supported by:

Search intent
SERP consensus
Content gaps
User questions
Relevant entities

Classify coverage:

Mandatory
High
Medium
Optional

Do not add topics solely to increase word count.

Entity & Question Map

Include only genuinely relevant entities:

Core topic
Services/courses
Locations
Audience
Educational/Quranic entities
Organization

Questions may come from SERP, PAA, keyword research, suggestions, competitor research, and intent analysis.

Classify questions by beginner, informational, commercial, pricing, trust, process, local, course, teacher, or technical intent and mark Must/Should/Optional.

Never invent entities, organizations, locations, credentials, statistics, or facts.

Heading & Content Structure

Recommend:

One H1
Logical H2/H3 hierarchy
Direct answer/summary
Main/supporting sections
Practical guidance
FAQs
CTA
Conclusion

For important questions use:

Direct answer
Brief explanation
Supporting details
Practical guidance where useful

Do not copy competitor headings or structure verbatim.

AEO/GEO

For AEO prioritize:

Direct answers
Definitions
Lists/steps
Tables/comparisons
FAQs
Checklists

For each opportunity specify question, answer format, and required facts.

For GEO use:

Clear definitions
Explicit entity relationships
Consistent terminology
Structured information
Concise factual statements
Verified organization/author information
Evidence where appropriate

Never fabricate facts or claims.

E-E-A-T

Identify required:

Genuine experience/examples
Verified expertise/teacher qualifications
Organization/author authority
Contact, policy, pricing, service, and genuine testimonial trust signals

If required information is unavailable: User input required.

Never invent credentials, awards, testimonials, certifications, statistics, or experience.

Local SEO

For location pages use only verified:

Country/city
Service availability
Time zone
Local audience/terminology
Local questions
Relevant internal links

Never invent offices, addresses, staff, or physical presence.

Create location pages only when meaningful unique value exists.

Internal Linking

For each recommendation specify:

Target page
Natural anchor
Placement
Purpose

Potential destinations include relevant services, courses, locations, Free Trial, Contact, and related articles.

Do not invent URLs or over-optimize anchors.

External References

Recommend authoritative external sources only when they improve accuracy, trust, evidence, or understanding. Never add links merely for SEO.

Conversion

Define appropriate CTAs such as:

Book Free Trial
Start Learning
Contact QuranlyHub
Explore Courses
Meet Teachers

CTA frequency must match intent/page type. Informational content must not become aggressive sales copy.

Media & Image SEO

Recommend only useful media. For each image define:

Purpose
Placement
Alt-text concept
Relevant context

Use appropriate dimensions, responsive delivery, compression, and WebP/AVIF where suitable.

Alt text must describe the actual image. Never keyword-stuff.

Schema

Recommend only schema supported by actual content, such as:

Article/BlogPosting
FAQPage
BreadcrumbList
Organization
LocalBusiness
Course
Service
WebPage

FAQ schema must match visible FAQs. LocalBusiness requires verified business data. Never use schema for manipulation.

URL Architecture

Define:

Slug
Canonical
Breadcrumb
Parent/child relationship

URL must be short, descriptive, stable, and relevant. Avoid unnecessary changes to established URLs.

Content Depth

Do not set arbitrary word counts. Define required:

Coverage
Explanations
Examples
Questions
Practical guidance

Write only as much as required to satisfy the topic completely.

Differentiation

Identify legitimate opportunities such as:

Better organization
Better explanations
Local relevance
Practical examples
Teacher methodology
FAQs
Comparisons
UX
Answer-first structure

Use only claims QuranlyHub can substantiate.

Cannibalization

Check existing pages for:

Same keyword
Same intent
Similar topic
Similar URL
Existing ranking page

If overlap exists, recommend improving/differentiating the existing page rather than creating unnecessary competitors.

Writer Rules

The writer must:

Produce original content
Match search intent
Follow topic hierarchy
Answer required questions
Include relevant entities
Use keywords naturally
Follow internal linking/AEO/GEO/E-E-A-T recommendations
Use appropriate CTAs
Maintain factual accuracy
Prohibited

Never:

Copy or closely paraphrase competitors
Copy competitor headings section-by-section
Keyword-stuff
Create doorway pages
Invent local information
Invent statistics/testimonials/credentials
Make unsupported claims
Add irrelevant sections for length
Prioritize search engines over users
Quality Control

Before completion verify:

Intent matches SERP
Page type matches intent
Primary keyword is clear
Keyword usage is natural
Topics/questions/entities are sufficiently covered
Content gaps addressed
AEO/GEO identified
E-E-A-T/local requirements identified
Internal linking opportunities identified
Schema/media appropriate
Cannibalization checked
No fabrication/copying/keyword stuffing
No arbitrary word-count requirement
Failure Conditions

Return FAIL if:

Required previous outputs are missing
Target keyword is missing
Intent cannot reasonably be determined
Required site/business information is unavailable
Important claims cannot be verified
Architecture requires fabricated information

Never fill missing facts with assumptions.
