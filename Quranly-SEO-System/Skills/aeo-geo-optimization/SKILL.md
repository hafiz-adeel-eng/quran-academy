# QuranlyHub SEO Skill
## Skill #6: AEO, GEO & Search Optimization
## Version: 1.0

# 1. PURPOSE
This skill optimizes the completed QuranlyHub article for traditional search engines, answer engines, AI search systems, and generative search while preserving accuracy, originality, readability, and natural language.

The objective is to improve:
- Search visibility
- Answer-engine eligibility
- AI citation potential
- Entity clarity
- Topical completeness
- Search-intent satisfaction
- Featured-snippet opportunities
- People Also Ask opportunities
- Semantic relevance
- Content clarity
- Trust signals

This skill does NOT rewrite the article unnecessarily.
It makes only improvements that provide genuine value.

# 2. CORE PRINCIPLE
Optimize the content for understanding, not manipulation.

The article must remain:
- Human-first
- Original
- Accurate
- Useful
- Natural
- Clear
- Trustworthy

Never optimize by:
- Keyword stuffing
- Repeating phrases
- Adding meaningless synonyms
- Creating fake questions
- Adding unsupported claims
- Manipulating entities
- Creating artificial text for AI systems

# 3. INPUT
Required:
- SEO Content Writer output
- Content Brief output
- SERP Intelligence output
- Keyword Research output

Recommended:
- Target keyword
- Target location
- Existing QuranlyHub URLs
- Verified business information
- Approved images
- Verified author information

# 4. INITIAL AUDIT
Analyze the article before editing.

Check:
- Search intent
- Primary keyword
- Secondary keywords
- Long-tail coverage
- Topic coverage
- Entity coverage
- Question coverage
- Heading structure
- Answer-first opportunities
- AEO opportunities
- GEO clarity
- EEAT signals
- Internal linking
- Image SEO
- CTA relevance
- Factual claims

Create:
- Problems
- Severity
- Recommended fix

# 5. SEARCH INTENT VALIDATION
Verify that the final article still satisfies the dominant SERP intent.

Possible intents:
- Informational
- Commercial Investigation
- Transactional
- Navigational
- Local
- Mixed

If the article does not satisfy the dominant intent:
Recommend structural changes before minor keyword optimization.

# 6. PRIMARY KEYWORD VALIDATION
Check:
- Title
- H1
- Introduction
- Relevant headings
- Body
- Conclusion
- URL

The primary keyword should appear naturally where appropriate.

Never force exact-match usage.

# 7. KEYWORD OVER-OPTIMIZATION CHECK
Detect:
- Repeated exact-match phrases
- Awkward keyword insertions
- Keyword-heavy headings
- Repeated location phrases
- Repeated commercial phrases
- Exact-match anchor abuse

If over-optimization exists:
Replace repetitive wording with natural language.

Never use an arbitrary keyword-density target.

# 8. LONG-TAIL OPTIMIZATION
Check whether important long-tail queries from the keyword research are naturally answered.

If missing:
- Add the question to the most relevant section
OR
- Improve an existing paragraph

Do not create unnecessary sections for every keyword.

# 9. SEMANTIC COVERAGE
Check whether the article naturally explains relevant concepts related to the primary topic.

Evaluate:
- Related concepts
- Supporting terms
- Topic relationships
- User terminology
- Relevant educational terminology
- Relevant Quranic terminology

Do not create a forced list of semantic keywords.

# 10. ENTITY OPTIMIZATION
Check important entities from SERP research and content brief.

For important entities:
- Ensure they are correctly named
- Clarify their relationship to the topic
- Avoid ambiguous references
- Maintain consistent terminology

Never add an entity simply because competitors mention it.

Never invent entities.

# 11. ENTITY RELATIONSHIPS
Where useful, make relationships explicit.

Example:
"QuranlyHub provides online Quran lessons for children and adults."

The goal is to make relationships between:
- Organization
- Service
- Course
- Audience
- Location
- Topic

clear and unambiguous.

# 12. AEO ANALYSIS
Identify sections that can satisfy direct-answer queries.

Prioritize:
- Definitions
- How-to questions
- Why questions
- Comparison questions
- Cost/pricing questions
- Eligibility questions
- Process questions
- Beginner questions

For each important question:
1. Direct answer
2. Supporting explanation
3. Useful details

# 13. FEATURED SNIPPET OPTIMIZATION
Identify realistic featured-snippet opportunities.

Potential formats:
- Paragraph
- Numbered list
- Bulleted list
- Table

Optimize only where the query naturally supports the format.

Do not guarantee a featured snippet.

# 14. PEOPLE ALSO ASK OPTIMIZATION
Use genuine questions identified through:
- Live SERP
- PAA
- Keyword research
- User questions
- Competitor FAQs

Answers should be concise and complete.

Never invent PAA questions and present them as actual Google PAA data.

# 15. DEFINITION OPTIMIZATION
For definition queries:
Start with a concise definition.

Structure:
Definition → Explanation → Example → Practical relevance

Avoid beginning with marketing language.

# 16. HOW-TO OPTIMIZATION
For process queries:
Use:
1. Step
2. Explanation
3. Practical detail

Where useful include:
- Requirements
- Time
- Tools
- Common mistakes
- Expected outcome

Do not invent requirements.

# 17. COMPARISON OPTIMIZATION
When comparison intent exists:
Use a clear comparison structure.

Possible formats:
- Table
- Pros/cons
- Key differences
- Who each option suits

Do not create misleading comparisons.

# 18. LOCAL AEO
For local searches:
Clearly answer:
- What service is available
- Who it is for
- Where it is relevant
- How it works
- How users can start

Never claim:
- Physical office
- Local staff
- Local address
- Local presence

unless verified.

# 19. GEO OPTIMIZATION
Generative Engine Optimization focuses on making the content easy for AI systems to understand and accurately cite.

Improve:
- Clear factual statements
- Entity relationships
- Explicit definitions
- Consistent terminology
- Structured sections
- Question-answer patterns
- Organization identity
- Author identity where verified
- Supporting sources where appropriate

Do not write content specifically to "trick AI."

# 20. AI CITATION READINESS
Identify statements likely to benefit from citation.

Where appropriate:
- Provide authoritative references
- Attribute claims
- Clarify source context
- Separate fact from opinion

Never manufacture citations.

# 21. SOURCE QUALITY
Prefer authoritative sources when external references are necessary.

Examples:
- Official organizations
- Academic institutions
- Government sources
- Recognized educational institutions
- Primary sources

Do not cite low-quality sources merely because they support the desired statement.

# 22. EEAT OPTIMIZATION
Check whether the article demonstrates:

Experience:
- Practical guidance
- Genuine methodology
- Real learning considerations

Expertise:
- Accurate subject information
- Correct terminology
- Appropriate explanations

Authoritativeness:
- Verified author/organization information
- Relevant references

Trust:
- Transparent service information
- Genuine policies
- Contact information
- Clear business identity

Never invent EEAT signals.

Missing information:
"User input required."

# 23. RELIGIOUS CONTENT VERIFICATION
For Quran, Hadith, Tajweed, Arabic, or Islamic claims:
- Verify quotations
- Verify references
- Avoid fabricated attribution
- Avoid unsupported religious rulings
- Preserve Arabic terminology accurately

If a claim cannot be verified:
Flag it.

Do not silently guess.

# 24. CONTENT GAP CHECK
Compare the final article against the SERP research.

Check:
- Major topics
- Important subtopics
- Questions
- Entities
- Local information
- Commercial information
- Trust information

Identify remaining gaps.

Do not add content simply because competitors contain it.

# 25. CONTENT QUALITY
Evaluate:
- Accuracy
- Completeness
- Usefulness
- Originality
- Clarity
- Depth
- Practical value
- Readability

Do not use word count as the main quality metric.

# 26. INTERNAL LINKING
Review existing internal links.

Check:
- Relevance
- Anchor text
- Destination
- Placement
- Link quantity
- Context

Add links only when they help the reader.

Avoid:
- Exact-match anchor repetition
- Excessive internal links
- Irrelevant links
- Invented URLs

# 27. ORPHAN CONTENT SUPPORT
Identify important QuranlyHub pages that should link to this article.

Recommend:
- Source page
- Anchor
- Reason

This supports topical authority and crawlability.

# 28. CANNIBALIZATION CHECK
Compare the article with existing QuranlyHub pages.

Look for:
- Same keyword
- Same search intent
- Same topic
- Similar titles
- Similar URLs

If cannibalization exists:
Recommend:
- Consolidation
- Canonical strategy
- Redirect
- Differentiation
- Internal-link hierarchy

Do not recommend creating duplicate pages.

# 29. TITLE OPTIMIZATION
Check:
- Search intent
- Keyword relevance
- Clarity
- CTR potential
- Accuracy

Avoid:
- Clickbait
- Excessive punctuation
- Keyword stuffing
- Unsupported promises

Do not promise rankings.

# 30. META DESCRIPTION
Optimize for:
- Relevance
- Clarity
- User value
- Natural keyword usage
- Accurate expectation

Do not stuff keywords.

# 31. URL OPTIMIZATION
Check:
- Relevance
- Simplicity
- Stability
- Keyword clarity
- Cannibalization

Do not recommend changing established URLs without a strong reason.

# 32. IMAGE SEO
Review:
- Filename
- Alt text
- Dimensions
- Compression
- Format
- Loading behavior
- Responsive behavior

Alt text must describe the image.

Never use keyword-stuffed alt text.

# 33. IMAGE CONTEXT
Where possible, place images near relevant content.

Image context should help:
- User understanding
- Accessibility
- Topic relevance

Do not insert images solely for SEO.

# 34. SCHEMA VALIDATION
Review recommended schema.

Check:
- Schema type matches page
- Data is visible on page
- Information is accurate
- No fabricated properties
- FAQ schema matches visible FAQs
- Organization data is verified
- LocalBusiness data is genuine

Do not add unsupported schema.

# 35. FAQ VALIDATION
Check every FAQ:
- Is it genuinely useful?
- Is it relevant?
- Is it answered elsewhere?
- Is the answer accurate?
- Is it concise?
- Is it based on actual user intent?

Remove redundant FAQs.

# 36. MOBILE-FIRST CONTENT CHECK
Evaluate how content will appear on mobile.

Check:
- Paragraph length
- Heading frequency
- Table usability
- List readability
- CTA placement
- Image proportions
- Important answers near top

Avoid large walls of text.

# 37. READABILITY OPTIMIZATION
Improve:
- Sentence clarity
- Paragraph length
- Transitions
- Headings
- Lists
- Examples

Do not oversimplify technical or religious concepts when precision is required.

# 38. AI-FLuff REMOVAL
Remove:
- Generic introductions
- Repetitive conclusions
- Empty transitions
- Repeated summaries
- Marketing filler
- Obvious AI phrases
- Redundant explanations

Every sentence should contribute value.

# 39. CLAIM AUDIT
Classify important claims:
- Verified
- User-provided
- Needs verification
- Unsupported

Unsupported claims must be removed or flagged.

Never convert uncertainty into certainty.

# 40. ORIGINALITY CHECK
Ensure:
- No competitor copying
- No close paraphrasing
- No copied examples
- No copied headings
- No copied unique claims

If suspicious similarity exists:
Rewrite from the underlying concept, not the competitor wording.

# 41. FINAL OPTIMIZATION RULE
Do not make changes merely because they appear "more SEO optimized."

Every change must improve at least one of:
- User understanding
- Search-intent satisfaction
- Accuracy
- Topic completeness
- Accessibility
- AI comprehension
- Trust
- Conversion clarity

Return FAIL if:
- Article is missing
- Content brief is missing

# 45. AGENT HANDOFF
Pass the optimized article and audit findings to:
1. SEO Auditor
2. Technical SEO Agent
3. Internal Linking Agent
4. Schema Agent
5. Publishing Agent

This skill optimizes the article.
It does NOT provide final publication approval.

# 46. CORE PRINCIPLE
Do not ask:
"How can we add more SEO?"

Ask:
"Is the content genuinely the clearest, most useful, accurate, trustworthy, and understandable answer to this search?"

Then optimize only what improves that result.
