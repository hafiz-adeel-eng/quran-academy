# Existing Page Optimization Workflow

## Purpose
Optimize an existing QuranlyHub page for better rankings, traffic, UX, AEO, GEO, and conversions without creating unnecessary new pages.

## Input
- Existing URL
- Primary keyword
- Target country/city
- Target audience
- Current page content
- Relevant existing QuranlyHub pages

## Step 1: Page Audit
Review the existing page for:
- Search intent
- Primary keyword targeting
- Title
- Meta description
- H1
- H2/H3 structure
- Content completeness
- Topic/entity coverage
- Search questions
- Keyword usage
- Search intent mismatch
- Internal links
- Images and alt text
- Schema
- E-E-A-T signals
- Local SEO signals
- CTA/conversion elements
- Mobile UX
- Core Web Vitals
- Indexability
- Canonical
- Robots directives
- URL structure

## Step 2: SERP Research
Use the SERP-Analysis skill.

Analyze relevant ranking pages and identify:
- Dominant search intent
- SERP features
- Common topics
- Missing topics
- Missing entities
- Missing questions
- Content weaknesses
- Local opportunities
- AEO opportunities
- GEO opportunities

Do not copy competitor content.

## Step 3: Keyword Review
Use Keyword-Research skill.

Identify:
- Primary keyword
- Secondary keywords
- Long-tail keywords
- Commercial keywords
- Local keywords
- Related terms
- Relevant entities

Use keywords naturally.
Never keyword-stuff.

## Step 4: Content Gap
Compare the current page against:
- SERP requirements
- User intent
- Relevant entities
- User questions
- Required subtopics

Separate:
- Missing content
- Weak content
- Outdated content
- Incorrect content
- Unnecessary content

## Step 5: Content Architecture
Use Content-Brief-SEO-Architecture skill.

Improve:
- Heading hierarchy
- Topic coverage
- Content flow
- Answer-first sections
- FAQ opportunities
- Conversion path

Do not rewrite good content unnecessarily.

## Step 6: On-Page Optimization
Use On-Page-SEO-optimization skill.

Optimize:
- SEO title
- Meta description
- H1
- H2/H3
- Introduction
- Keyword placement
- Semantic relevance
- URLs
- Image alt text
- Readability
- CTR elements

Avoid forced keyword insertion.

## Step 7: AEO/GEO
Use AEO-GEO-Optimization skill.

Ensure:
- Clear direct answers
- Question-based sections where useful
- Definitions
- Structured information
- Entity clarity
- Factual consistency
- Citation-worthy statements
- Easy-to-extract answers

Never write specifically for AI at the expense of human users.

## Step 8: Internal Linking
Use Internal Linking + Topical Cluster skill.

Add only relevant internal links.

For each link check:
- Relevance
- Destination
- Natural anchor
- User value
- Topic relationship

Avoid excessive exact-match anchors.

## Step 9: Images
Use Image-SEO-Optimization skill.

Check:
- Relevant image
- Correct placement
- Descriptive filename
- Useful alt text
- Compression
- WebP/modern format
- Lazy loading where appropriate
- Dimensions
- Mobile display

## Step 10: Schema
Use Schema Markup + Structured Data SEO skill.

Add only schema supported by visible page content.

Validate:
- Correct type
- Required properties
- No misleading markup
- No fabricated information

## Step 11: Technical SEO
Use Technical-SEO-Audit skill.

Check:
- Indexability
- Canonical
- Robots
- Sitemap inclusion
- Status code
- Mobile usability
- Page speed
- Core Web Vitals
- Broken links
- Redirects
- Duplicate content
- HTTPS
- Crawlability

## Step 12: Mobile UX
Use Core Web Vitals + Mobile UX Optimization skill.

Mobile is the highest priority.

Check:
- Layout
- Padding
- Margins
- Font sizes
- Buttons
- Navigation
- Images
- Tables
- Forms
- CTA visibility
- Horizontal overflow
- Touch targets
- Loading performance

Then check desktop layout.

## Step 13: Freshness
Use Content Freshness + Content Maintenance skill.

Update outdated:
- Facts
- Links
- Statistics
- Examples
- Services
- FAQs
- Screenshots
- Dates

Do not change content merely to appear fresh.

## Step 14: Final SEO QA
Use Pre-Publish SEO QA skill.

Verify:
- Search intent
- Keyword targeting
- Content completeness
- Internal linking
- On-page SEO
- Schema
- Images
- Technical SEO
- AEO/GEO
- E-E-A-T
- Local SEO
- Mobile UX
- Core Web Vitals
- Conversion elements

## Step 15: Decision
Return one of:

READY:
Page is ready for publishing.

NEEDS_REVISION:
List exact issues that must be fixed.

BLOCKED:
Publishing cannot proceed because required information/access is missing.

## Rules
- Preserve useful existing content.
- Do not rewrite everything without reason.
- Never fabricate facts, credentials, locations, reviews, prices, or statistics.
- Never copy competitors.
- Never keyword-stuff.
- Never add irrelevant sections just to increase word count.
- Never create a new page if the existing page can satisfy the intent.
- Avoid keyword cannibalization.
- Prioritize users over search engines.
- Mobile UX is the highest design priority.
- Do not publish until final QA passes.

## Output
Return:
1. Current page diagnosis
2. Issues found
3. Content gaps
4. SEO improvements
5. Technical issues
6. Internal-link recommendations
7. Image recommendations
8. Schema recommendations
9. Mobile UX issues
10. Required changes
11. Final status
