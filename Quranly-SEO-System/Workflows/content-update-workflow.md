# QuranlyHub Content Update Workflow

## PURPOSE
Maintain and improve existing QuranlyHub content without unnecessary rewriting, keyword stuffing, or loss of existing rankings.

## INPUT
Required:
- Existing URL
- Current article/page
- Primary keyword
- Target location if applicable
- Target audience

Optional:
- Previous SEO data
- Search Console data
- Analytics data
- New business/service information
- New images
- User feedback

Never invent missing information.

## STEP 1 — UPDATE DISCOVERY

Review the page and identify:
- Outdated information
- Broken links
- Missing topics
- Missing questions
- Changed search intent
- Weak sections
- Old statistics
- Old examples
- Outdated services
- Missing entities
- New relevant search terms
- Ranking/click opportunities

Do not update content merely to change its date.

## STEP 2 — FRESHNESS RESEARCH

Use:
- Content Freshness + Content Maintenance
- Keyword Research
- SERP Analysis when needed

Check current:
- Search intent
- SERP patterns
- Competitor coverage
- User questions
- Relevant topics/entities
- Local information

Use live data when available.

## STEP 3 — CONTENT DECISION

Classify each section:

KEEP
- Accurate
- Useful
- Still relevant

UPDATE
- Outdated
- Incomplete
- Weak
- Needs clarification

REMOVE
- Incorrect
- Irrelevant
- Redundant
- No longer useful

ADD
- Important missing topic
- Important question
- Relevant entity
- Useful practical information

Do not remove useful content simply because competitors do not have it.

## STEP 4 — CONTENT UPDATE

Use:
- SEO Content Writer

Update content to:
- Improve accuracy
- Improve usefulness
- Match current intent
- Improve clarity
- Cover important gaps
- Preserve successful sections
- Maintain natural keyword usage

Never:
- Rewrite everything without reason
- Add filler
- Keyword stuff
- Copy competitors
- Fabricate facts

## STEP 5 — SEO RE-OPTIMIZATION

Use relevant:
- On-Page SEO
- Search Intent + Title Optimization
- AEO/GEO Optimization

Check:
- Title
- Meta description
- H1-H3
- Primary keyword
- Related terms
- Search intent
- Entities
- Questions
- AEO answers
- GEO clarity

Only change the title if evidence supports the change.

## STEP 6 — INTERNAL LINKS

Use:
- Internal Linking + Topical Cluster

Review existing links.

Add, remove, or update links when:
- A relevant page exists
- A destination changed
- A new supporting page exists
- The link improves topical relationships

Avoid excessive links and repetitive anchors.

## STEP 7 — IMAGE UPDATE

Use:
- Image SEO Optimization

Check:
- Relevance
- Image freshness
- Alt text
- Filename
- Compression
- Dimensions
- WebP/appropriate format
- Lazy loading

Replace images only when there is a genuine UX, relevance, branding, or performance benefit.

## STEP 8 — SCHEMA

Use:
- Schema Markup + Structured Data SEO

Verify schema still matches visible content.

Update or remove outdated schema.

Never add fabricated properties.

## STEP 9 — TECHNICAL + MOBILE REVIEW

Use:
- Technical SEO Audit
- Core Web Vitals + Mobile UX

Check:
- Indexability
- Canonical
- Robots
- Sitemap
- Broken links
- Redirects
- Duplicate content
- Mobile layout
- Performance
- Core Web Vitals risks

Prioritize mobile UX.

## STEP 10 — AEO/GEO REVIEW

Ensure updated content contains:
- Clear answers
- Accurate definitions
- Explicit entities
- Structured information
- Useful FAQs where appropriate
- Factual consistency

Do not optimize unnaturally for AI systems.

## STEP 11 — FINAL QA

Use:
- Pre-Publish SEO QA

Verify:
- Search intent
- Content quality
- Freshness
- Keywords
- Internal links
- Images
- Schema
- Technical SEO
- AEO/GEO
- E-E-A-T
- Mobile UX
- Keyword stuffing
- Cannibalization

## UPDATE SAFETY

Preserve existing SEO equity.

Do not unnecessarily change:
- URL
- Strong title
- Useful headings
- High-performing content
- Existing backlinks

If a URL must change:
- Evaluate redirect requirements
- Preserve link equity
- Update internal links
- Verify canonical

## PUBLISH GATE

PASS:
All important updates are verified and QA passes.

FAIL:
Critical issues remain.

BLOCKED:
Required information or access is unavailable.

Never publish on FAIL or BLOCKED.

## CORE RULE

Update with evidence, not for the sake of freshness.

Preserve what works.
Improve what is weak.
Remove what is wrong.
Add what users now need.

Accuracy, usefulness, search intent, and user experience come before artificial SEO changes.
